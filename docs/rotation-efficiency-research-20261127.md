# Rotation pace and efficiency research
Separate paired team-only and player-aware factor model on the same verified regulation box cohort. Shared estimated pace uses mean of both box possession estimates. Points per 100 uses that common denominator. Own and opponent exposure terms are regularized associations, not measured on-court effects. Fixed priors, no target data, no injury requests, no promotion. Existing saved rotations are used without new downloads. Old forecast and score receipts unchanged. Candidate scores and model receipts are separate; this is not yet covered by historical_five_results settlement or full period simulation. Native test and independent forward evaluation required.
