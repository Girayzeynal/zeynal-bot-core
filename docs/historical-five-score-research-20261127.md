Connect existing identifiable minute contrast fit and identical cohort team-only
control to the independent historical-five rotation. Uses native archived boxes,
actual observation clocks and same season, no current injury publication.
Future target is excluded from fitting, scores published before existing five
minute boundary into separate research files. Candidate and control model hashes
retained. Fitted terms cover only part of rotation; output represented minutes.
No causal claim, no live model update. Existing minimum 30 native boxes is a
model feasibility check, not a 100-match requirement. Strict historical holdout
uses actual source clocks; its existing 60 total game research split is separate
from fit, not a deployment gate. It can abstain; retrospective scores do not
prove prospective superiority. Actual UserLAnd data and CI still required.
